	Краткая информация о проекте: клиент-серверное приложение по бронированию авиабилетов, пользватель отправляет запрос на бронирование с указанными данными (своими, рейса), 
  сервер их обрабатывает и выдает сообщение об успешности/неуспешности  брони.

	Техническая информация: "сервер"  класс main, отдельными потоками к нему поступают "заявки бронирования", которые он обрабатывает, поступление осуществляется с случайно задержкой 0-1с, 
  чтобы эмитировать реальную работу. Классы Airport, booking,flight,person,plane являются служебными и нужны для организации работы сервиса бронирования.
Основные классы лежат по пути src/main/java/org.example/...
Файл тестов src/test/java/MainTest
Запуск основной программы - запустить Main
Запуск тестов - MainTest
